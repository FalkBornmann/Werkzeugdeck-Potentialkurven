# Potentialkurven

Werkzeugdeck → Elektrochemie → Datenauswertung.

Statische Browser-Anwendung zur Darstellung und Auswertung von Potentialkurven.
Zum lokalen Verwenden diesen Ordner über einen HTTP-Server ausliefern und index.html öffnen.
Messdaten und Exporte werden im Browser verarbeitet.

[Werkzeugdeck](https://werkzeugdeck.pages.dev/#elektrochemie)
